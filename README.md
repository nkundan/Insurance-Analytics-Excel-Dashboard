# Insurance Analytics Dashboard using Excel

## Project Overview
This project demonstrates an interactive Insurance Analytics Dashboard built using Microsoft Excel. The dashboard provides insights into insurance policy performance by analyzing key business metrics and visualizing them through charts, pivot tables, slicers, and KPI cards.

## Objective
The objective of this project is to analyze insurance policy data and help stakeholders monitor business performance through an easy-to-use dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

## Dataset
The dataset contains approximately 5,000+ insurance policy records, including:
- Customer Details
- Policy Information
- Premium Details
- Payment Frequency
- Policy Status

## Dashboard KPIs
- Total Premium Collected
- Average Premium Value
- Policy Count
- Policy Status Distribution
- Policy Type Breakdown
- Payment Frequency Analysis
- Premium Collection Trend
- Retention Rate

## Key Insights
- Analyzed premium collection trends across insurance policies.
- Identified policy status distribution (Active, Lapsed, and Terminated).
- Compared policy types and payment frequency patterns.
- Created an interactive dashboard for business reporting and decision-making.
